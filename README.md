## The roast

> The senator who wrote the law governing artificial intelligence converted the bill to PDF by printing it, scanning it, and emailing the scan to himself.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-sentence roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that is set). The program validates the roast against the competition
gate first: 1–320 characters, exactly one sentence, not only whitespace.
Two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
